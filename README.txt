MOHITE CONSTRUCTION WEBSITE
===========================

WHAT IS INCLUDED
- Home, About Us, Services, Blog, Contact and Social Media Plan pages
- Responsive HTML/CSS/JavaScript design
- Mobile navigation, scroll reveal animation, hover interactions
- WhatsApp enquiry form (opens WhatsApp with the enquiry prefilled)
- Click-to-call and WhatsApp links
- Google Maps embed centered on Khamgaon, Buldhana, Maharashtra
- SEO page titles, meta descriptions, Open Graph basics, sitemap.xml, robots.txt
- Business card image supplied by the client in assets/

HOW TO PREVIEW
1. Extract the ZIP.
2. Open index.html in a modern browser.
3. For best local testing, use VS Code Live Server or another local static server.

BEFORE PUBLIC LAUNCH
1. Confirm the domain and replace https://www.mohiteconstruction.in in canonical URLs and sitemap.xml.
2. Replace illustrative Unsplash images with actual Mohite Construction project photos. Do not present stock images as completed company projects.
3. Replace Facebook/Instagram placeholder links with the actual business profile URLs after creating them.
4. Confirm service area, business contact details, exact service scope and all claims.
5. The enquiry form prepares a WhatsApp message; it does not store submissions or send email. A backend/form service is needed for database or email lead capture.
6. The map marks Khamgaon generally, not a verified office address.
7. This is a static HTML/CSS/JS implementation, not a WordPress CMS installation. The assignment document names WordPress as its platform requirement; use this build as a front-end website prototype or migrate the design into WordPress if WordPress is mandatory.

SEO NOTES
- Add Google Search Console and submit sitemap.xml after domain deployment.
- Configure HTTPS, image compression, caching and analytics at hosting level.
- Add LocalBusiness structured data only after verifying the exact business address and public business details.
- Add real project descriptions, unique photos, testimonials (with permission) and actual social profile URLs.
